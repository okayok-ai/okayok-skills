# Brand naming

Pick a product/brand name that is brandable, available, and easy to rank for. The goal: a distinctive spelling you own, so searching it finds you and only you.

## Criteria
- **Distinctive, ownable spelling.** A unique coined word (even a slight twist on a common word) ranks and gets indexed fast, because nothing else competes for it. Generic words (common dictionary terms, category words) are near-impossible to rank and get auto-corrected by search engines.
- **Short and typeable.** Easy to say, spell, and remember.
- **Consistent with the family.** If building a family of products, decide a naming convention and keep to it, while still giving each product a distinct name.
- **Pronounceable in your main markets.**

## Checks to run for each candidate (before committing)
1. **Real search-engine results** for the plain name: is there an existing product/software/site with the same name, especially in the same category? Check actual search results, not just an API or a narrow long-tail query — a plain-term search is what users and the market see. Watch for the engine auto-correcting your name to a common word (a sign it's too generic).
2. **Domain availability** (the exact name; note that a subdomain of an existing brand domain is a free fallback).
3. **Code host availability** (e.g. GitHub org/repo; note hosts that disallow certain characters like underscores).
4. **Social handle availability** across the platforms you'll use; aim for one unified handle.
5. **Trademark** search in the relevant registries for your markets.
6. **App store availability** (Apple App Store, Google Play, browser extension stores) if you'll ship there.

## Decision
- Prefer the candidate that is clean across search, domain/subdomain, code host, trademark, and stores.
- If the exact domain is taken but the name is otherwise clean, a subdomain of your brand domain is a fine, free launch path.
- Record the final name and the handle convention so every later stage uses them consistently.

## Anti-patterns
- Naming after a generic category word and expecting to rank for it.
- Choosing a name without checking real search results first.
- Different handles/spellings across platforms.
